# QA фильм-сайта

Сервер: `python3 -m http.server -d film/site 8776`. Playwright берётся из `~/code/AppBrandHUB/node_modules/playwright`.

- `node qa.cjs [конфиг]` — матрица экранов (ru-390, ru-375se, ru-1440, en-390, en-1280, ru-430, ru-768, ru-1920): листает все остановки, снимает кадры в эту папку, пишет `report-*.json`. Проверки: вылезание за экран, обрезанный текст, карточка под шапкой, телефон в кадре, наложение подписей созвездия, ошибки консоли и сети.
- `node scen.cjs` — 19 сценариев: карта, RU⇄EN, reduced-motion, подменный Telegram.WebApp, клавиатура, «Авто» до конца, отказ manifest.

Headless рисует без GPU — плавность мерить в настоящем браузере (лог ROCH #1006).
