## Устройство

Единый источник правды — папка **`src/`**:
- `src/data.js` — все узлы, связи, зоны, координаты, `meta` (цифры портфолио) и `APPHUB_SYNC` (общая база)
- `src/style.css` — Liquid Glass UI · `src/app.js` — логика · `src/public.html`, `src/internal.html` — шаблоны
- `src/supabase.sql` — схема общей базы для совместной правки (таблица `apphub_map`, строки `main` и `v2`)

После правки в `src/` пересобери самодостаточные файлы:

```bash
python3 src/build.py
```

Это вшивает CSS/JS/данные в **`v2/index.html`** (витрина) и **`AppHub-карта-экосистемы.html`** (внутренняя).
Корневой `index.html` — замороженная карта v1, build его не трогает.

Типы узлов: `hub` (слой петли), `mini` (продукт / направление), `case` (живой кейс из портфолио — компактная пилюля справа).
У кейса поле `pf` — slug в портфолио-боте: экраны подтягиваются из галереи `apphub-portfolio-livid.vercel.app/gallery/<slug>/`.

## Общая база (совместная правка)

С 1 июля карта умела читать и писать общую базу в Supabase. **С сентября 2026 прежний проект недоступен** — карта
работает от `src/data.js`, редактор сохраняет правки в браузере и один раз предупреждает. Чтобы вернуть совместную правку:
создать Supabase-проект → выполнить `src/supabase.sql` → вписать `url` и anon-ключ в `APPHUB_SYNC` в `src/data.js` → `build.py`.

Без базы канон делается так: Редактор → ⤓ JSON → прислать файл, он вшивается в `src/data.js`.
